# Legacy Backup (Vanilla JavaScript & CSS Prototype)

Folder ini memuat kode arsip versi prototipe awal (*Zero-Build architecture*) sebelum dimigrasikan ke **React + Vite**:

- **`js/`**:
  - `app.js` (Hash router Vanilla JS)
  - `student.js` (Modul render tampilan Siswa)
  - `admin.js` (Modul render tampilan Admin)
  - `audit.js` (Modul render jejak audit)
  - `store.js` (State management berbasis localStorage)
  - `api.js` (REST client awal)
- **`css/`**:
  - `style.css` (Custom CSS styles awal)

> **Catatan**: Seluruh fitur dan logika di atas saat ini sudah diimplementasikan dan dikelola secara modern di dalam folder `src/` menggunakan komponen React (`.jsx`).
